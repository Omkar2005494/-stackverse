## 📖 Overview

**Stackverse** transforms abstract Data Structures & Algorithms into a rich, interactive 3D cyberpunk universe. 

Instead of staring at dry terminal logs or 2D diagrams, developers can **write authentic core code in Python, C++, Java, C, or JavaScript** and watch their algorithms execute in real-time 3D space with step-by-step variable inspection, Big-O metrics, and synchronized procedural sound effects.

---

## 🌟 Key Highlights & Major Features

### 1. 🌐 Universal Multi-Language Code Studio
Write native code from the core — complete with `#include`, `vector`, `def`, `class`, and `main()`! Stackverse's AST execution engine instruments your code into synchronized real-time 3D animations across **5 top languages**:

- ⚡ **JavaScript (ES6+)**: Arrow functions, destructuring, and native objects.
- 🐍 **Python 3**: Indentation blocks, `range()`, f-strings, list comprehensions, and tuple swaps (`a, b = b, a`).
- ⚙️ **C++ (STL)**: Headers, `std::vector`, `std::stack`, `std::queue`, and `swap()`.
- ☕ **Java**: Class structures, `static void main`, arrays (`int[]`, `int[][]`), and `System.out.println`.
- 🔤 **C**: Standard headers (`#include <stdio.h>`), fixed arrays, `sizeof()` calculations, and `printf()`.

---

### 2. 🌀 8 Interactive 3D DSA Realms

| Realm | Key Algorithms & Visualizations | 3D Interactions |
| :--- | :--- | :--- |
| **🌀 2D Matrix Grid** | Spiral Matrix Traversal, 90° Rotation, In-Place Transposition | 3D coordinate scanning `[r][c]`, live cell swaps, row reversals |
| **📊 Array & Sorting** | Bubble Sort, Binary Search, Linear Search, Quick Sort | Dynamic bar heights, swap arcs, search pointers, comparison pings |
| **🌲 Tree Nexus** | Binary Search Tree (BST), BFS, DFS (Inorder/Preorder/Postorder) | Branch generation, node highlight pulses, depth-level traversal |
| **🕸️ Graph Realm** | Vertex & Edge Management, Graph BFS / DFS, Network Routing | Holographic cyber nodes, neon directional edges, hop animations |
| **🏔️ Heap Citadel** | Min-Heap & Max-Heap, Sift Up/Down, Extract Root | Dynamic tree & array hybrid view, bubbling element sift animations |
| **🔗 Linked List** | Singly Linked List, Insert Head, Delete Node, List Reversal | Glowing pointer nodes, linked chain connections, memory shifts |
| **🗼 Stack Kingdom** | LIFO Stack, Push, Pop, Peek, Overflow & Underflow alerts | Cyber blocks dropping from the sky, mechanical floor impacts |
| **🚀 Queue City** | FIFO Stream, Enqueue, Dequeue, Peek | Smooth sliding conveyor lane, stream entry & exit dynamics |

---

### 3. 🔊 Zero-Asset Procedural Web Audio API Engine
- **100% Procedural**: No external `.mp3` or `.wav` files — generated purely via Web Audio API oscillators.
- **0ms Latency**: Linear envelopes tuned for instant tactile feedback (Punchy mechanical push thuds, crystal pop whooshes, holographic laser scan pings, and pentatonic BST chimes).
- **Universal Cross-Browser Auto-Unlock**: Silent buffer warmup for macOS/iOS Safari and gesture listeners for Chrome, Brave, Edge, and Firefox.

---

### 4. 🎮 Cyberpunk Gamification & Progression
- **Interactive Step Debugger**: Step forward, jump, pause, control execution speed (Slow, Normal, Warp).
- **Live Scope & Log Inspector**: Real-time snapshot of variables, call stack, and stdout logs.
- **Cyber Hero Identity**: Customizable avatars, archetypes (Cyber Architect, Quantum Coder, Neural Hacker), and color themes.
- **XP, Levels & Achievements**: Earn XP for algorithm completions, level up through ranks, and unlock trophies.

## 🧰 Tech Stack & Architecture

- **Frontend & UI**: React.js 18, Vite, Framer Motion, Lucide Icons, Tailwind / Custom Cyber Glassmorphism CSS.
- **3D Graphics Engine**: Three.js, React Three Fiber (`@react-three/fiber`), React Three Drei (`@react-three/drei`).
- **Code Execution & AST Transpiler**: Sandboxed JavaScript & Multi-Language Transpilation AST Pipeline (`codeTo3DInterpreter.js`).
- **Audio Engine**: Web Audio API Procedural Synthesizer (`soundFX.js`).
- **Authentication & Cloud Save**: Firebase Auth & Cloud Firestore.
- **Deployment**: Vercel CI/CD Pipeline.

## ⚙️ Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or yarn

### 1. Clone the repository:
```bash
git clone https://github.com/Omkar2005494/-stackverse.git
cd -stackverse
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start local development server:
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for production:
```bash
npm run build
```
