# 🚀 StackVerse

A 3D Gamified Data Structures & Algorithms Learning Platform

🌐 Live Demo: https://stackverse-nu.vercel.app

---

## 📖 Overview

StackVerse transforms traditional Data Structures & Algorithms learning into an immersive gaming experience.

Explore interactive worlds based on real DSA concepts, perform operations visually, gain XP, unlock achievements, and progress through ranks while mastering fundamental computer science topics.

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Omkar2005494/-stackverse.git
cd -stackverse
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

---

## 🏆 Achievements System

Users can unlock achievements by performing operations across different worlds:

- Stack Master
- Queue Commander
- Tree Explorer
- DFS Hunter
- Heap Builder
- Heap Extractor

Each achievement rewards XP and contributes to overall progression.

---

## 📈 Progression System

Level Progression:

- Level 1–4 → Adventurer
- Level 5–9 → Explorer
- Level 10–14 → Pathfinder
- Level 15–19 → Guardian
- Level 20+ → Realm Master
